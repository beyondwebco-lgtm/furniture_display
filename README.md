# Dhareena Cloud Swivel Chair: single product site (v2)

Next.js 15 + React 19 + Lenis (smooth scroll).

1. `npm install`
2. `npm run dev` -> http://localhost:3000
3. Edit name, price, WhatsApp number, copy, specs: `lib/product.js`
4. Chair images: `public/images/side-cut.webp`, `back-cut.webp` (transparent background)
5. Deploy: push to GitHub, import in Vercel.

Effects: preloader counter, curtain page transition on nav links, masked text reveals,
pinned scroll hero with fake 3D turn (side -> back), parallax, line-draw specs.
Better results: reshoot chair on plain wall from 4-8 angles, remove background, swap in.
